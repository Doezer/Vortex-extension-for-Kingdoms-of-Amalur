Initial Vortex extension for Kingdoms of Amalur: Re-Reckoning.

- Steam, GOG, and Epic discovery, with manual game-folder selection.
- Installation of replacement PAKs, data/video files, Mod Framework packages and Lua scripts, and ReShade presets.
- Refusal of ambiguous variants, incompatible paths, standalone tools, and save-game downloads.
- Windows/Linux CI on Node 22 and 24, reproducible ZIP packaging, research notes, and a live validation checklist.

Install the attached ZIP through Vortex's Extensions page and restart Vortex. Requires Vortex 1.9 or newer.

All 86 automated tests passed on Node 22 and 24, including Windows and Linux CI.
Live Vortex and in-game validation remains pending, so this is a prerelease.
Test payloads are synthetic; no third-party mod or game assets are included.

Mods replacing the same PAK conflict as whole files; their contents are not merged.
Framework and ReShade dependencies must be installed separately as instructed by the mod authors.
